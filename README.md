
### Bioinformatics tools and analysis scripts
- `phylogenetic_analysis.sh` → Automated Bash pipeline for phylogenetic analysis of protein sequences, integrating multiple bioinformatics tools to perform sequence alignment using different algorithms (MAFFT and ClustalW), alignment trimming (trimAl), and automatic selection of the best trimmed alignment and the most suitable amino acid substitution model (ModelTest-NG) based on the Bayesian Information Criterion (BIC). The selected alignment and substitution model are then used for Maximum Likelihood (ML) phylogenetic tree reconstruction using RAxML-NG, including 1,000 bootstrap replicates, consensus tree generation, and bootstrap support assessment. The input is a FASTA file containing protein sequences, and the outputs include multiple sequence alignments, trimmed alignments in different formats, substitution model selection results, and phylogenetic trees with bootstrap support values.
